# MoodWave 服务器部署指南

> 服务器: 106.52.8.176 (腾讯云)  
> GitHub: https://github.com/lyqqqq66666/MoodWave

---

## 一、首次部署（服务器上执行）

### 1. SSH 登录服务器
```bash
ssh root@106.52.8.176
```

### 2. 安装 Docker（如果还没有）
```bash
curl -fsSL https://get.docker.com | bash
systemctl enable docker
systemctl start docker

# 安装 Docker Compose v2
apt install -y docker-compose-plugin
```

### 3. 克隆项目
```bash
cd /root
git clone https://github.com/lyqqqq66666/MoodWave.git
cd MoodWave
```

### 4. 创建 .env 文件
```bash
cat > .env << 'EOF'
DB_PASSWORD=你的安全密码
DEEPSEEK_API_KEY=sk-xxxxx
DASHSCOPE_API_KEY=sk-xxxxx
JWT_SECRET=你的JWT密钥改成随机字符串
EOF
```

### 5. 启动
```bash
chmod +x deploy.sh
./deploy.sh
```

## 二、日常更新（最常用）

### 方式 A：一键脚本
```bash
ssh root@106.52.8.176
cd /root/MoodWave
./deploy.sh
```

### 方式 B：手动命令
```bash
ssh root@106.52.8.176
cd /root/MoodWave
git pull origin main
docker compose down backend
docker compose build --no-cache backend
docker compose up -d backend
```

### 方式 C：只重启（.env 或 docker-compose.yml 没变时）
```bash
ssh root@106.52.8.176
cd /root/MoodWave
git pull origin main
docker compose up -d --build backend
```

## 三、常用运维命令

| 操作 | 命令 |
|------|------|
| 查看后端日志 | `docker compose logs backend --tail 50 -f` |
| 查看数据库日志 | `docker compose logs db --tail 20` |
| 重启后端 | `docker compose restart backend` |
| 重启数据库 | `docker compose restart db` |
| 进入后端容器 | `docker compose exec backend bash` |
| 进入数据库 | `docker compose exec db psql -U moodwave` |
| 查看运行状态 | `docker compose ps` |
| 完全停止 | `docker compose down` |
| 完全停止+删数据 | `docker compose down -v` ⚠️ 危险 |
