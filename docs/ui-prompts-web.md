# MoodWave 网页端UI提示词

> 用于GPT Image/Figma生成完整原型
> **风格：可爱治愈风 (Macaron & Soft)**
> **平台**：Web应用（响应式，同时适配桌面端和移动端浏览器）

---

## 通用规范

- **画布尺寸**:
  - 桌面端: 1440x900px
  - 移动端: 375x812px (iPhone 14) 或 360x800px (Android)
- **响应式断点**:
  - `<768px`: 移动端（底部TabBar，单列布局）
  - `768-1023px`: 平板（可折叠侧边栏，双列卡片）
  - `≥1024px`: 桌面端（固定侧边栏，三列卡片）
- **PWA支持**: 可安装到手机主屏幕（伪装成APP）
- **风格**: 可爱治愈风，马卡龙色系
- **字体**: Nunito(英文标题) + Quicksand(英文正文) + PingFang SC(中文圆体)

### 色彩（马卡龙色系）
- 背景: 暖白#FFF8F0 或 浅色#FFFFFF
- 卡片: rgba(255,255,255,0.8)
- 文字: #2D3436 / rgba(45,52,54,0.6) / rgba(45,52,54,0.4)
- 品牌色: #FFB5C2(樱花粉) / #A8E6CF(薄荷绿) / #FFD93D(明黄)

### 情绪色彩（Soft Moods）
- 开心: #FFD166 珊瑚色
- 悲伤: #C7E8CA 鼠尾草绿
- 愤怒: #EF8D7B 珊瑚红
- 平静: #90E0EF 薄荷蓝
- 焦虑: #8ECAE6 天蓝
- 平淡: #F5F5DC 燕麦色

### 组件规范
- 卡片: 白色90%背景，圆角32px，柔和阴影
- 按钮: 胶囊形圆角9999px，柔和阴影hover加深
- 输入框: 圆角20px，focus品牌色边框
- 阴影: 0 4px 16px rgba(0,0,0,0.06) 柔和阴影

## 响应式设计详解

### 桌面端 (>1024px)
- **布局**: 左侧固定侧边栏(240px) + 主内容区
- **导航**: 侧边栏导航，选中项左侧4px品牌粉竖条
- **交互**: 鼠标悬停效果（上浮+阴影加深）
- **快捷键**: 支持键盘快捷键（如`Esc`关闭弹窗）
- **内容宽度**: 最大1200px居中，保持阅读舒适度

### 平板端 (768-1023px)
- **布局**: 侧边栏收起为图标模式(64px宽) + 主内容区
- **导航**: 悬停侧边栏展开（显示文字）
- **卡片**: 双列布局，间距16px
- **字体**: 适当减小（标题24px→20px）

### 移动端 (<768px)
- **布局**: 无侧边栏，底部TabBar导航
- **导航**: 底部TabBar（4个Tab：首页/趋势/音乐/我的）
- **触控优化**: 所有可点击元素≥44px
- **卡片**: 单列布局，宽度100%（留白16px）
- **手势**:
  - 下拉刷新（所有列表页）
  - 左滑删除（记录列表）
  - 右滑返回（有层级的页面）
- **字体**: 适当减小（标题20px→18px）
- **表单**: 输入框高度≥48px（移动端友好）

### 自适应组件示例

| 组件 | 桌面端 | 移动端 |
|------|--------|--------|
| 侧边栏 | 固定显示(240px) | 隐藏，用底部TabBar |
| 卡片布局 | 3列 | 1列 |
| 按钮 | 宽度自适应 | 宽度100%（全宽） |
| 输入框 | 宽度400px | 宽度100% |
| 弹窗 | 居中，宽度600px | 底部向上滑出（Sheet） |
