## 二、产品概述（1 页，500 字以内）

### 产品是什么

MoodWave 灵音是一款面向 Z 世代大学生的 **AI 情绪健康管理平台**，通过「情绪日记 → AI 分析 → 可视化音乐治愈 → QQ 社交互动」的闭环体验，帮助年轻人记录、理解、管理自己的情绪。

### 核心差异化

现有竞品要么只做记录（心岛日记）、要么只做冥想（潮汐）、要么只做社区。MoodWave 的差异化在于：**情绪记录 → AI 分析 → 专属音乐治愈 → 数据洞察 → QQ 社交共鸣，形成完整的情绪健康管理闭环**。

### 为什么需要这个产品

> 数据来源：105 份跨校大学生问卷（腾讯问卷 #26446726）

- **78.1%** 的大学生每周至少经历 1 次负面情绪
- **72.4%** 的焦虑来自就业/考研，66.7% 来自学业压力
- **67.7%** 对音乐治愈产品持正面态度
- **45.7%** 最想要"干净的治愈界面"
- **37.1%** 希望有 AI 像朋友一样倾听

## 三、痛点分析（1 页）

### 痛点 1：大学生情绪问题普遍但缺乏有效的日常管理工具

| 数据 | 说明 |
|------|------|
| 78.1% 每周至少 1 次负面情绪 | 情绪困扰是常态，不是个例 |
| 47.6% 自我否定 | "觉得自己不够好"是普遍心理 |
| 25.7% 靠听音乐转移注意力 | 音乐是排名第一的自我调节方式 |

### 痛点 2：现有工具存在明显不足（来自 Q10 问卷）

- **记录太麻烦**："打字太累不想记"（排名第一的弃用原因）
- **记录了没反馈**：单纯记录没有后续价值
- **缺乏情感连接**：冷冰冰的工具，用完即走
- **隐私不安全**：不想把心情存到别人的服务器

### 痛点 3：QQ 生态缺少"情绪层"

- QQ 现有"状态"功能只有文字 + emoji，**缺乏 AI 驱动的情绪感知**
- 大学生日常在 QQ 空间、QQ 群中表达情绪，但这些情绪**没有被结构化地记录和分析**
- QQ 是 Z 世代最高频的社交工具，但缺乏"情绪陪伴"的产品心智

## 四、解决方案（2-3 页，核心部分）

### 4.1 产品架构

```
用户情绪入口（30 秒快速记录）
       ↓
  AI 情绪分析引擎（DeepSeek）
       ↓
  ┌────┼────┬──────────┐
  ▼    ▼    ▼          ▼
音乐   数据   灵音伙伴    QQ 社交
治愈   洞察   AI 陪伴    互动层
```

### 4.2 六大核心功能模块

| 模块 | 功能 | 解决什么痛点 |
|------|------|-------------|
| **情绪录入** | 选表情 + 调强度 + 写日记 + 拍照，5 步 30 秒 | "记录太麻烦" |
| **AI 情绪分析** | DeepSeek 实时分析情绪文本，返回解读 + 建议 | "记录了没反馈" |
| **可视化音乐** | 情绪 → Tone.js 生成音乐 + Canvas 粒子动画 | "音乐治愈"需求 |
| **灵音伙伴** | AI 虚拟角色陪伴，有记忆、有个性、可捏脸 | "缺乏情感连接" |
| **数据分析** | 30 天趋势图 + 热力日历 + MBTI 交叉分析 | "了解自己的情绪模式" |
| **解忧角** | 匿名轻社交，调解者角色 + 正向反馈 | "隐私安全 + 社区共鸣" |

### 4.3 核心创新点

1. **情绪 → 音乐实时映射**: 开心 = 明快金橙粒子，悲伤 = 低频翡翠绿波纹，6 种情绪对应 6 套独立的音乐 + 视觉参数，Tone.js + Canvas API 实时渲染
2. **AI 虚拟角色记忆系统**: 角色会记住"你在准备考试""你上周失眠了"等关键事件，从对话中学习用户，不是一次性对话机器人
3. **QQ 社交情绪感知层**: 情绪日记 → QQ 状态卡片 / QQ 空间动态 / 群聊心情天气，让情绪数据驱动社交互动
4. **完整数据闭环**: 记录 → 分析 → 趋势 → MBTI 个性化推荐，用户能看见自己的情绪规律

## 五、PCG 业务结合方案（2 页，评审重点！）

### 5.1 为什么选 QQ？

| 维度 | 说明 |
|------|------|
| **用户量级** | QQ 月活数亿，其中大学生是核心用户群 |
| **场景匹配** | QQ 状态、QQ 空间、QQ 群聊天然承载情绪表达 |
| **技术可行** | QQ 小程序生态成熟，开放平台 API 丰富 |
| **差异化价值** | QQ 目前缺乏 AI 驱动的情绪感知层，MoodWave 可以填补 |

### 5.2 四个具体结合点

#### 🥇 结合点 1：QQ 状态/心情升级（最强）

| 现在的 QQ 状态 | MoodWave 升级后 |
|---------------|----------------|
| 文字 + emoji（手动设置） | AI 自动分析情绪 → 动态音乐可视化状态卡片 |
| 静态展示 | 情绪粒子动画 + 霓虹配色 |
| 无法记录历史 | 形成"情绪时间线"，可回顾 |

**展示方式**: Demo 中展示情绪记录后 → "同步 QQ 状态"→ 生成可分享的状态卡片

#### 🥈 结合点 2：QQ 空间情绪动态

- 情绪日记可一键分享为 QQ 空间动态（带音乐可视化封面）
- 形成"情绪社交内容生态"：朋友看到你的情绪动态 → 互动 → 共鸣
- 匿名选项保护隐私（不想露名的可以用虚拟角色形象发布）

#### 🥉 结合点 3：QQ 群聊心情天气

- AI 分析群内发言情绪倾向 → 生成"群心情天气"（晴/多云/雨）
- 增强群体归属感："原来大家最近都焦虑考研"
- 群主可查看群情绪趋势，适时组织关怀活动

#### 加分结合点 4：QQ 音乐推荐联动

- 情绪 → 音乐推荐链路对接 QQ 音乐曲库
- MVP 阶段用 Tone.js 生成展示效果，后续对接 QQ 音乐 API

### 5.3 叙事话术（评委记住这句话）

> **MoodWave 灵音 = QQ 社交的 AI 情绪感知层**
>
> 让 QQ 从"通讯工具"升级为"情绪陪伴平台"

### 5.4 落地路线图

| 阶段 | 时间 | 形态 |
|------|------|------|
| **短期（比赛 Demo）** | 2026.5 | 独立 PWA + QQ 风格 UI + "分享到 QQ 空间"模拟入口 |

## 八、技术实现（1-2 页）

### 8.1 技术架构图

```
┌─────────────────────────────────────────────┐
│          用户浏览器 / PWA（手机安装）          │
│    Next.js 14 + TypeScript + Tailwind CSS    │
│  Tone.js + Canvas API + Recharts + Zustand  │
└──────────────────┬──────────────────────────┘
                   │ HTTP/SSE
┌──────────────────▼──────────────────────────┐
│        Python FastAPI 后端（腾讯云服务器）      │
│  ┌──────────┐ ┌──────────┐ ┌─────────────┐  │
│  │情绪 CRUD  │ │ AI Agent │ │ 社区/数据分析 │  │
│  │/api/moods │ │ DeepSeek │ │ /api/posts   │  │
│  └──────────┘ └──────────┘ └─────────────┘  │
│              PostgreSQL 16 数据库             │
└─────────────────────────────────────────────┘
```

### 8.2 技术栈一览

| 层 | 技术 | 选型理由 |
|----|------|---------|
| 前端 | Next.js 14 (App Router) | SSR + 路由系统成熟 |
| UI | Tailwind CSS + Shadcn/UI | 快速开发 + 视觉一致 |
| 动效 | Framer Motion + Canvas API | 页面切换 + 音乐粒子 |
| 状态管理 | Zustand | 轻量 + TypeScript 友好 |
| 图表 | Recharts | React 原生图表 |
| 音频 | Tone.js + Web Audio API | 浏览器原生音频生成 |
| 后端 | Python FastAPI + SQLModel | 高性能 + 自动文档 |
| 数据库 | PostgreSQL 16 | JSONB + Docker 持久化 |
| AI | DeepSeek API (deepseek-v4-pro) | 中文理解强 + SSE 流式 |
| 部署 | Vercel + Docker + Nginx | 三路部署覆盖比赛要求 |

### 8.3 AI 能力

- **DeepSeek 情绪分析**: 输入用户日记 → 输出情绪类型/强度/关键词/建议
- **SSE 流式对话**: 灵音伙伴实时打字输出，模拟真实对话
- **角色人设系统**: 7 个预设角色（小喵/小狐狸/小星球等），各有独立 persona
- **Prompt 动态构建**: 根据角色 + MBTI + 星座动态生成 system prompt

### 8.4 开发模式亮点

- 🛠 **Vibe Coding**: AI 辅助开发，7 天单人完成全栈 MVP
- 📝 **问卷数据驱动**: 先调研验证需求，再动手写代码
- 🚀 **双比赛并行**: PCG 产品大赛 + OpenClaw 玩虾大赛同时推进
- 🔗 **对话式开发**: Prompt → 代码 → 联调 → 部署 → URL 完整链路
