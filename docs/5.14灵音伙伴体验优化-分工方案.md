## 二、补充优化分工

### WorkBuddy 后端任务（2 个，约 30 分钟）

#### W1. 新增会话重命名接口 ⬜

**接口**：`PATCH /api/companion/conversations/{conversation_id}`

**修改文件**：`backend/src/api/companion.py`

**实现要点**：
1. 新增请求模型：

```python
class ConversationUpdate(BaseModel):
    """更新会话请求"""
    title: str  # 1-40 字，不允许为空
```

2. 新增路由处理函数：
   - 验证会话属于当前用户（复用已有的 `select + where` 模式）
   - 校验标题长度：1 ≤ len(title) ≤ 40
   - 更新 `conversation.title` 和 `conversation.updated_at`
   - 返回 `{ code, msg, data: { id, title, updated_at } }`

3. 插入位置：在 `delete_conversation` 函数上方（约 575 行附近）

**参考代码骨架**：

```python
@router.patch("/companion/conversations/{conversation_id}")
async def update_conversation(
    conversation_id: int,
    request: ConversationUpdate,
    current_user: User = Depends(get_current_user),
    session: Session = Depends(get_session),
):
    """
    修改会话标题
    """
    try:
        statement = select(CompanionConversation).where(
            CompanionConversation.id == conversation_id,
            CompanionConversation.user_id == current_user.id,
        )
        conversation = session.exec(statement).first()

        if not conversation:
            return JSONResponse({
                "code": 404,
                "msg": "会话不存在",
                "data": None,
            }, status_code=200)

        # 校验标题长度
        title = request.title.strip()
        if len(title) < 1 or len(title) > 40:
            return JSONResponse({
                "code": 400,
                "msg": "标题长度需要 1-40 个字符",
                "data": None,
            }, status_code=200)

        conversation.title = title
        conversation.updated_at = datetime.utcnow()
        session.add(conversation)
        session.commit()

        return {
            "code": 0,
            "msg": "ok",
            "data": {
                "id": conversation.id,
                "title": conversation.title,
                "updated_at": conversation.updated_at.isoformat(),
            },
        }

    except Exception as e:
        logger.error("update_conversation error: %s", str(e)[:200])
        return JSONResponse({
            "code": 500,
            "msg": f"更新会话失败: {str(e)[:100]}",
            "data": None,
        }, status_code=200)
```

#### W2. Agent done 事件增强（可选）⬜

**修改文件**：`backend/src/api/companion.py`（`send_message_agent` 函数）

**改动**：在 `done_payload` 中新增两个字段：

```python
# 在 save_ai_reply() 中，保存后获取 ai_msg.id 和 ai_msg.created_at
done_payload = json.dumps({
    "type": "done",
    "content": {
        "reply": reply_text,
        "mood_type": agent_result.get("mood_type", request.mood_type),
        "music_recommendation": music_rec,
        "memory_refs": agent_result.get("memory_refs", []),
        "agent_status": agent_result.get("agent_status", "completed"),
        "nodes_executed": agent_result.get("nodes_executed", []),
        # 👇 新增
        "assistant_message_id": ai_msg_id,
        "assistant_created_at": ai_msg_created_at,
    },
}, ensure_ascii=False)
```

**实现方式**：在 `save_ai_reply()` 中把保存后的 `ai_msg.id` 和 `ai_msg.created_at` 通过 `nonlocal` 传出给 `done_payload`。

**重要**：这个改动需要把 `save_ai_reply()` 从异步函数改为同步（或用 `asyncio.Event` 同步），确保 done 事件在保存完成后发出。如果改动风险大，可以跳过——前端用本地时间兜底即可。

### Codex 前端任务（7 个，约 3-4 小时）

按依赖顺序排列。W1 完成后 Codex 才能做 C2、C3。

#### C0. 接入 greeting 接口（从原 P0 继承）⬜

**目标**：进入灵音伙伴页时，调用 `GET /api/companion/greeting` 获取动态欢迎语，替换硬编码欢迎文案。

**接口文档**：

```
GET /api/companion/greeting
Headers: Authorization: Bearer <token>

Response:
{
  "code": 0,
  "msg": "ok",
  "data": {
    "greeting": "主欢迎语",
    "starter_messages": ["开场白1", "开场白2", "开场白3"],
    "source": "today_mood | default | fallback",
    "mood_type": "anxious | null",
    "character": "cat"
  }
}
```

**实现要点**：
- 页面加载时调用接口，用 `greeting` 替换固定欢迎语
- `starter_messages` 作为快捷回复按钮展示在输入框上方
- 如果接口失败，fallback 到本地默认文案

## 五、Codex 实现注意事项

1. **API Base URL**：`http://localhost:8000/api`
2. **认证**：所有接口需要 `Authorization: Bearer <token>` header
3. **SSE 流式**：使用 `EventSource` 或 `fetch + ReadableStream`，注意 `text/event-stream` 格式
4. **状态管理**：建议在现有 Zustand store 中扩展（`companionStore` 或扩展现有 store）
5. **响应式**：手机端历史浮层全屏覆盖，PC 端右侧抽屉
6. **Shadcn/UI 组件**：浮层用 `Sheet`，确认弹窗用 `AlertDialog`，按钮用 `Button` + `DropdownMenu`
