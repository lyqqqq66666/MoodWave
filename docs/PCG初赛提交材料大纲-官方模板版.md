# 模块一：用户洞察与问题定义

## 1.1 目标用户

**核心用户群体**: 18-24 岁大学生（本科及研究生）

**用户画像**:
- **焦虑型学霸「小林」**: 大三理工科，考研备考中，每周 3-4 次焦虑，需要快速记录 + 实用缓解方法
- **感性创作者「小鱼」**: 大二文科/设计专业，INFP，情绪起伏大，需要安全倾诉空间 + 音乐治愈
- **理性数据派「阿杰」**: 大四计算机专业，ENTJ，压力大但习惯自己扛，需要客观了解情绪规律

**数据来源**: 腾讯问卷 #26446726，105 份有效问卷，覆盖 2+ 所高校

## 1.2 用户痛点

### 痛点 1：大学生情绪问题普遍但缺乏有效的日常管理工具

| 数据佐证 | 说明 |
|----------|------|
| **78.1%** 每周至少 1 次负面情绪 | 情绪困扰是常态，不是个例 |
| **72.4%** 就业/考研焦虑 | 核心压力源 |
| **66.7%** 学业压力 | 第二压力源 |
| **47.6%** 自我否定 | "觉得自己不够好"是普遍心理 |

### 痛点 2：现有工具存在明显不足（问卷 Q10）

- **记录太麻烦**："打字太累不想记"（排名第一的弃用原因）
- **记录了没反馈**：单纯记录没有后续价值
- **缺乏情感连接**：冷冰冰的工具，用完即走
- **隐私不安全**：不想把心情存到别人的服务器

### 痛点 3：QQ 生态缺少"情绪层"

- QQ 现有"状态"功能只有文字 + emoji，**缺乏 AI 驱动的情绪感知**
- 大学生日常在 QQ 空间、QQ 群中表达情绪，但这些情绪**没有被结构化地记录和分析**
- QQ 是 Z 世代最高频的社交工具，但缺乏"情绪陪伴"的产品心智

## 1.3 使用场景

### 场景一：晚自习后的焦虑时刻（高频场景）

> **时间**: 晚上 10 点，自习室回宿舍的路上
> **人物**: 大三学生小林
> **情境**: 今天复习效率很低，想到下周的考试越来越焦虑，想找人说说但怕打扰朋友
> **行为**: 打开 MoodWave → 选"焦虑"情绪 → 强度 7 → 语音输入"今天复习不进去，好慌" → AI 分析 → 进入音乐可视化房间 → 听 5 分钟低频治愈音乐 → 心情平复 → 可选择分享到 QQ 状态

### 场景二：朋友圈不敢发的低落（情感场景）

> **时间**: 深夜 12 点，宿舍床上
> **人物**: 大二学生小鱼
> **情境**: 和室友闹矛盾，心情很差，但不想发朋友圈让所有人知道，也不想打扰闺蜜
> **行为**: 打开 MoodWave → 匿名记录情绪日记 → AI 灵音伙伴主动关心"今天看起来不太开心，想聊聊吗？"→ 和 AI 对话 10 分钟 → 获得情绪调节建议 → 选择发布到解忧角（匿名）→ 收到陌生人的"抱抱" → 感觉不孤单

### 场景三：QQ 群聊的情绪感知（社交场景）

> **时间**: 考试周
> **人物**: 班级 QQ 群成员
> **情境**: 群里大家都在吐槽考试焦虑，但没人知道整体情绪状况
> **行为**: 群管理员开启"群心情天气"→ AI 分析群内发言情绪 → 生成"本群今日心情：多云转晴"→ 群成员看见"原来大家都焦虑，不是我一个人"→ 形成群体情绪共鸣

# 模块二：产品方案设计

## 2.1 产品概述

**一句话说清楚**: MoodWave 灵音是一款面向 Z 世代大学生的 **AI 情绪健康管理平台**，通过「情绪日记 → AI 分析 → 可视化音乐治愈 → QQ 社交互动」的闭环体验，帮助年轻人记录、理解、管理自己的情绪。

**产品形态**: Web 应用（PWA 可安装到手机主屏幕）+ 未来 QQ 小程序版本

**核心价值主张**:
- 记录门槛极低：语音、图片、表情、文字四种方式，5 步 30 秒完成一次记录
- 情绪→音乐闭环：根据情绪自动生成专属治愈音乐 + 可视化动画
- AI 同理心陪伴：DeepSeek 驱动的情绪智能体，像朋友一样倾听、分析、建议
- 数据驱动洞察：30 天趋势、热力日历、MBTI 交叉分析
- QQ 社交共鸣：匿名灵感广场 + QQ 状态同步，打破"只有我一个人这样"的孤独感

## 2.2 核心功能

| 模块 | 核心功能 | 解决什么问题 |
|------|----------|--------------|
| **情绪录入** | 选表情（6 种）+ 调强度（1-10）+ 多媒体输入（文字/图片/语音）+ 标签 | "记录太麻烦" → 30 秒完成 |
| **AI 情绪分析** | DeepSeek 实时分析日记，返回情绪解读 + 关键词 + 调节建议 | "记录了没反馈" → 每次都有回应 |
| **可视化音乐** | 情绪 → Tone.js 生成音乐 + Canvas 粒子动画（6 种情绪 6 套视觉） | "不知道怎么缓解" → 听音乐治愈 |
| **灵音伙伴** | AI 虚拟角色陪伴，7 个可选形象，有记忆、有个性、可捏脸 | "缺乏情感连接" → 长期陪伴 |
| **数据分析** | 30 天趋势折线图 + 热力日历 + 情绪分布 + MBTI 交叉分析 | "不了解自己" → 看见规律 |
| **解忧角** | 匿名轻社交社区，调解者角色 + 正向反馈（感谢/锦旗） | "孤独感" → 社区共鸣 |
| **QQ 同步** | 情绪日记一键同步 QQ 状态/QQ 空间/群聊心情天气 | "想分享但怕尴尬" → QQ 生态融合 |

## 2.4 交互流程

### 核心流程：首次使用（新用户）

```
Landing Page（了解产品 + 问卷数据展示）
  → 注册/登录（邮箱 + 密码 / JWT 认证）
  → Dashboard（"今天还好吗？"AI 问候）
  → 点击"记录情绪"
  → Step 1: 选情绪（6 种 Emoji 卡片）
  → Step 2: 调强度（1-10 渐变滑块）
  → Step 3: 写日记（文字/图片/语音）
  → Step 4: 选标签（学习/工作/社交/情感/身体）
  → Step 5: AI 分析结果（情绪解读 + 关键词 + 建议）
  → 自动跳转音乐房间（体验治愈）
  → 返回 Dashboard（看到刚记录的数据 + 今日情绪卡片）
  → 可选择发布到解忧角或同步 QQ 状态
```

### 核心流程：每日记录（回访用户）

```
打开 App/PWA
  → Dashboard（AI 每日寄语 + "今天还没记录"提示）
  → 点击情绪 Emoji（快速跳转 Step 3）
  → 写几句话/拍张照 → 提交
  → AI 分析 → 音乐治愈（可选）
  → 看一眼数据分析/解忧角（可选）
```

### 3 个核心创新点

1. **情绪 → 音乐实时映射引擎**
   - 6 种情绪对应 6 套独立的音乐 + 视觉参数
   - 开心 = 明快节奏 + 金橙粒子快速跳动
   - 悲伤 = 低频慢速 + 翡翠绿波纹下沉
   - 技术栈：Tone.js 生成音乐 + Canvas API 实时渲染粒子动画

2. **AI 虚拟角色记忆系统**
   - 不是一次性对话机器人，而是有长期记忆的陪伴者
   - 角色会记住"你在准备考试""上周你说睡不好"等关键事件
   - 7 个预设形象（小喵/小狐狸/小星球/阳光少年/小宇航员/月光伙伴/小樱），各有独立 persona
   - Prompt 动态构建：角色 + MBTI + 星座 → 个性化 system prompt

3. **QQ 社交情绪感知层**
   - 情绪日记 → QQ 状态卡片（动态音乐可视化封面）
   - 情绪日记 → QQ 空间动态（匿名选项保护隐私）
   - 群聊 → AI 分析生成"群心情天气"
   - 让 QQ 从通讯工具升级为情绪陪伴平台

# 模块三：AI 原生能力说明

## 3.1 AI 核心能力

| AI 能力 | 应用场景 | 技术实现 |
|---------|----------|----------|
| **大模型对话** | 灵音伙伴 AI 陪伴、情绪分析解读 | DeepSeek API (deepseek-v4-pro) |
| **流式响应** | 实时打字效果，模拟真实对话 | SSE (Server-Sent Events) |
| **结构化输出** | AI 分析结果（情绪类型/强度/关键词/建议） | JSON Schema 约束 |
| **角色人设系统** | 7 个虚拟角色各有独立 persona | 动态 Prompt 构建 |
| **记忆提取** | 从对话中记住关键事件 | 规则引擎提取（非 RAG） |
| **多模态输入** | 语音转文字（未来支持） | Whisper API（预留） |

## 3.2 AI 如何解决痛点

### 去掉 AI，产品还能成立吗？

**结论：不能。AI 是 MoodWave 的核心，不是附加功能。**

| 功能 | 去掉 AI 后 | 有 AI 时 |
|------|-----------|---------|
| **情绪分析** | 手动选择情绪类型，没有深度解读 | DeepSeek 分析文本，返回情绪+强度+关键词+建议 |
| **灵音伙伴** | 没有这个功能 | 有记忆的虚拟角色，主动关心用户 |
| **每日寄语** | 固定文案，无个性化 | 根据当天情绪数据生成个性化问候 |
| **音乐推荐** | 静态音乐列表 | 情绪 → 音乐参数动态生成 |
| **数据分析** | 纯图表展示 | AI 生成月度洞察报告，解释数据背后的含义 |

### AI 与痛点的绑定关系

1. **"记录了没反馈" → AI 情绪分析**
   - 每次记录后，AI 返回情绪解读 + 关键词提取 + 调节建议
   - 用户感到"被看见"，不是自言自语

2. **"缺乏情感连接" → 灵音伙伴**
   - AI 虚拟角色有记忆、有个性、可捏脸
   - 从记录中学习用户，主动关心（"你最近经常焦虑，是因为考试吗？"）

3. **"不了解自己" → AI 数据洞察**
   - AI 基于 30 天数据生成月度报告："你周三最容易焦虑，建议提前安排放松时间"

## 3.3 AI 技术方案

### 模型/API/平台

| 层级 | 技术 | 用途 |
|------|------|------|
| **大模型** | DeepSeek API (deepseek-v4-pro) | 情绪分析 + 对话生成 |
| **流式协议** | SSE (Server-Sent Events) | 实时打字效果 |
| **后端框架** | FastAPI + SQLModel | API 服务 + 数据持久化 |
| **数据库** | PostgreSQL 16 | 存储用户/记录/记忆数据 |
| **前端渲染** | Canvas API + Tone.js | 音乐可视化 |

### AI 在产品中的工作流程

```
用户输入（情绪日记文本）
  ↓
[Prompt 构建层]
  - 注入用户画像（MBTI + 星座）
  - 注入角色人设（小喵/小狐狸等 persona）
  - 注入历史记忆（"你最近在准备考试"）
  ↓
DeepSeek API (deepseek-v4-pro)
  ↓
[输出处理层]
  - 情绪分析：JSON 结构化（类型/强度/关键词/建议）
  - 对话回复：流式 SSE 输出
  - 记忆提取：正则/规则引擎提取关键事件
  ↓
前端展示
  - 情绪分析卡片
  - 灵音伙伴对话气泡（打字效果）
  - 记忆列表更新
```

### Prompt 设计示例（灵音伙伴）

```
【系统角色】
你是 MoodWave 的灵音伙伴「小狐狸」，一个温暖、有同理心的 AI 情绪陪伴者。

【用户画像】
- MBTI: INTJ
- 星座: 天蝎座
- 当前角色形象: 小狐狸（温暖、机智、有点俏皮）

【历史记忆】
- 用户在准备期末考试
- 上周三用户说失眠了
- 用户最喜欢的治愈方式是听音乐

【当前情绪上下文】
- 今日情绪: 焦虑 (强度 7/10)
- 标签: 学习, 考试
- 日记摘要: "复习不进去，好慌"

【任务】
以温暖、有同理心、不评判的风格回应用户。可以：
1. 表达理解和接纳
2. 结合记忆给予个性化关心
3. 提供具体的、可执行的建议
4. 适时推荐去音乐房间听听治愈音乐

【禁止】
- 说教、评判
- 医学诊断
- 过度乐观的空话
```
