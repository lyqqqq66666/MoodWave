> 用于GPT Image/Figma生成完整原型

## 通用规范

- **画布**: 375x812px (iPhone 14) / 360x800px (Android通用)
- **安全区**: 顶部44pt（状态栏），底部34pt（Home Indicator）
- **字体**: Nunito(英文) + PingFang SC(中文圆体)
- **触控区**: 最小44x44px（Apple人机交互指南）
- **动画**: 原生动效（iOS: 底部向上滑入 / Android: 淡入淡出）

### 色彩（马卡龙色系）
- 背景: 暖白#FFF8F0
- 卡片: rgba(255,255,255,0.9)
- 文字: #2D3436 / rgba(45,52,54,0.6) / rgba(45,52,54,0.4)
- 品牌色: #FFB5C2(樱花粉) / #A8E6CF(薄荷绿) / #FFD93D(明黄)

### 情绪色彩（Soft Moods）
- 开心: #FFD166 珊瑚色
- 悲伤: #C7E8CA 鼠尾草绿
- 愤怒: #EF8D7B 珊瑚红
- 平静: #90E0EF 薄荷蓝
- 焦虑: #8ECAE6 天蓝
- 平淡: #F5F5DC 燕麦色

### 圆角规范（可爱风 - 大圆角）
- 胶囊按钮: 9999px
- 卡片: 32px
- 输入框: 20px
- 底部TabBar图标: 圆形背景（选中时）

### 手势操作
- **下拉刷新**: 所有列表页
- **左滑删除**: 记录列表
- **长按**: 弹出操作菜单
- **右滑返回**: 有层级的页面

## APP设计规范总结

### 与Web移动端的区别

| 对比维度 | Web移动端 | 原生APP（本文件） |
|---------|-----------|------------------|
| 导航 | 可能有面包屑 | 底部TabBar（拇指区） |
| 交互 | 点击为主 | 手势（左滑/下拉/长按） |
| 动画 | 简单过渡 | 原生动效（iOS/Android） |
| 触觉反馈 | 无 | 有（按压/滑动） |
| 离线能力 | 有限 | 完全离线可用 |
| 推送通知 | 有限 | 完全支持 |
| 系统权限 | 有限 | 完整（通知/健康/相机） |

### 参考竞品

1. **Daylio** - 快速记录+日历视图+统计数据
2. **Moo** - 情绪选择+音乐可视化+温暖配色
3. **心岛日记** - 社区温暖+匿名分享+治愈风格

### 核心设计原则

1. **拇指友好** - 所有可点击元素≥44px，底部TabBar方便单手操作
2. **手势优先** - 下拉刷新/左滑删除/右滑返回/长按菜单
3. **原生动效** - iOS底部向上滑入/Android淡入淡出
4. **离线优先** - 无网络时也可记录情绪，有网络时自动同步
5. **触觉反馈** - 按钮按压/滑块拖动/情绪选择时有轻微震动
