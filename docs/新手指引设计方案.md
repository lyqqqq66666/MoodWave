# MoodWave 灵音 — 新手指引设计方案

> **目标读者**: Codex（GPT，前端开发）  
> **创建日期**: 2026-05-03  
> **来源**: WorkBuddy 基于 woshipm.com 新手指引设计研究 + 2025 UX Onboarding 最佳实践 + MoodWave 项目现状  
> **适用范围**: Web 端 + 移动端（响应式）

---

## 一、为什么需要新手指引？

### 结论：非常有必要

MoodWave 不属于"常态型产品"（购物、新闻、信息社交类），而是一个**创新复合型产品**，融合了：

- 情绪记录（5 步分步录入）
- AI 情绪分析（DeepSeek）
- 可视化音乐房间（Tone.js + Canvas）
- 灵感广场（社区）
- AI 陪伴对话（灵音伙伴）

**用户痛点**：新用户登录后面对 Dashboard，不清楚 MoodWave 的核心价值在哪、和普通日记 App 有什么区别、音乐房间怎么玩。

**引导目标**（按优先级）：
1. 让用户在 **30 秒内** 体验一次完整"记录 → AI分析 → 音乐治愈"闭环
2. 突出产品差异化（可视化音乐房间是核心记忆点）
3. 降低后续使用中的学习成本（空状态引导 + 上下文提示）

---

## 二、设计原则

| 原则 | 说明 |
|------|------|
| **可跳过** | 所有引导页均可随时跳过，给用户掌控感 |
| **做中学** | 不让用户"看"引导，而是"做"引导 — 教学式引导 |
| **渐进式披露** | 首次只教核心流程，高级功能在恰当时机出现 |
| **情绪化语言** | 不用"点击这里"的冰冷文案，用 MoodWave 的温柔口吻 |
| **品牌一致** | 赛博治愈 + Glassmorphism 2.0 视觉风格贯穿始终 |
| **移动优先** | 先在 375px 宽度上设计，再适配桌面端 |
| **3-5 步上限** | 不超过 5 个引导屏，人类短时记忆上限 |

---

## 三、触发时机

```
用户注册成功 → 自动跳转到新手指引 → 完成后进入 /dashboard
用户登录（首次登录且未完成过引导） → 自动跳转到新手指引
```

**判断方式**：在 `useAuthStore` 的 user 对象中增加字段 `onboarding_completed: boolean`，或 localStorage 存储 `moodwave_onboarding_done`。

**已有用户不受影响**：如果 localStorage 已有标记，直接进 /dashboard。

## 四、引导流程设计（5 步）

### 整体结构

```
┌─────────────────────────────────────────────────────┐
│  顶部: 跳过按钮 (始终可见)                            │
│  中部: 引导内容区 (动画过渡)                          │
│  底部: 步骤圆点 + 上一步/下一步按钮                    │
│  背景: 渐变动画背景 (与品牌一致)                       │
└─────────────────────────────────────────────────────┘
```

### Step 1: 欢迎页（品牌认知）

**目标**: 建立情感连接，传递品牌调性

```
┌───────────────────────────────────────┐
│                                       │
│           MoodWave Logo 动画           │
│          (波浪呼吸动画)                │
│                                       │
│    "欢迎来到灵音"                      │
│                                       │
│    记录情绪的潮汐，遇见内心的风景        │
│                                       │
│    🌊 每一次情绪，都会变成一段           │
│       专属于你的声音与颜色              │
│                                       │
│    [开始探索] 按钮                     │
│                                       │
└───────────────────────────────────────┘
```

**视觉**：
- Logo 居中放大，带 `animate-pulse` 呼吸效果
- 背景：柔和的渐变 (pink → mint → lavender)
- 装饰：浮动的半透明圆形光晕 (glass orbs)
- 按钮：圆角全宽，粉色渐变，带阴影

**移动端适配**：
- Logo 尺寸：w-32 h-32 (128px)
- 文字：text-2xl
- 内边距：px-6

**桌面端适配** (lg:)：
- Logo 尺寸：w-40 h-40 (160px)  
- 文字：text-4xl
- 最大宽度：max-w-md mx-auto

│  │   DeepSeek 温柔解读你的情绪     │     │

│  └─────────────────────────────┘     │

**交互**：卡片依次滑入 (stagger animation)，每个卡片 delay 增加 150ms。

**视觉**：
- 卡片：Glassmorphism 风格 (`bg-white/70 backdrop-blur-xl rounded-3xl`)
- 序号：用圆形徽章 (`bg-gradient-to-br from-[#ffb4c4] to-[#8de1d5]`)
- 每个卡片左侧有色条，颜色对应情绪色板

**移动端**：卡片堆叠，占满宽度  
**桌面端**：卡片水平排列或两栏布局

### Step 3: 可视化音乐房间预览（核心记忆点）

**目标**: 这是 MoodWave 最大的差异化功能，需要一个令人"哇"的预览

```
┌───────────────────────────────────────┐
│                                       │
│    "你的情绪，可以听见"                 │
│                                       │
│  ┌─────────────────────────────┐     │
│  │                             │     │
│  │    [音乐房间预览动画]         │     │
│  │                             │     │
│  │    🎵 粒子随节奏跳动          │     │
│  │    🌈 颜色随情绪变化          │     │
│  │    🔮 波纹扩散效果           │     │
│  │                             │     │
│  │    [▶ 试听按钮]              │     │
│  │                             │     │
│  └─────────────────────────────┘     │
│                                       │
│    "试听一下平静模式的氛围音乐"          │
│                                       │
└───────────────────────────────────────┘
```

**实现方式**：
- 嵌入一个简化版的音乐可视化组件（MiniMusicVisualizer）
- 使用 Tone.js 播放一段预设的 Calm 氛围音乐（10秒循环）
- Canvas 或 CSS 动画展示粒子效果
- 不同情绪类型的音乐可切换预览（happy/calm/sad 三种按钮）

**移动端**：预览卡片 16:9 或正方形比例  
**桌面端**：预览卡片 max-w-lg mx-auto

**注意**：这里的"试听"是独立的小组件，不依赖用户已有情绪数据。使用预设参数。

**目标**: 让用户真正完成一次情绪记录，获得即时 AI 反馈

```

│  ├──────┼──────┼──────┤              │
│  │ 😠   │ 😢   │ 🙂   │              │
│  │ 愤怒  │ 悲伤  │ 平淡  │              │
│  └──────┴──────┴──────┘              │
│                                       │
│    选中后的 intensity slider          │
│    ●━━━━●━━━━━━━━━○                  │
│    1          5          10           │
│                                       │

│    [写下几行字...]                     │
│                                       │
│    [分析我的心情 →]                    │
│                                       │
└───────────────────────────────────────┘
```

**重要**：这个步骤的数据**不计入用户的正式情绪记录**。它只是为了展示 AI 分析的效果。

**交互流程**：
1. 用户选择情绪 → 图标高亮，显示对应颜色光环
2. 滑动 intensity → 实时渐变色变化
3. 可选填写文字（非必填，但建议引导填写）
4. 点击"分析我的心情" → 调用 `/api/ai/chat` 或 `/api/analytics/analyze` 接口
5. 展示 AI 分析结果卡片（模拟真实的 Step 5 报告）
6. 动画过渡到 Step 5

**视觉**：
- 情绪按钮：复用现有的 MoodSelector 组件逻辑，圆角正方形 2×3 网格
- 选中态：对应情绪色的发光边框 + 缩放动画
- 滑块：复用现有的 IntensitySlider
- 加载态：分析中显示 skeleton + 温柔文案（"正在感受你的心情..."）

### 7.4 localStorage 键

```typescript
const ONBOARDING_KEY = "moodwave_onboarding_completed"
const DASHBOARD_TOOLTIP_KEY = "moodwave_dashboard_tooltip_done"

export function hasCompletedOnboarding(): boolean {
  if (typeof window === "undefined") return true
  return localStorage.getItem(ONBOARDING_KEY) === "true"
}

export function markOnboardingCompleted(): void {
  localStorage.setItem(ONBOARDING_KEY, "true")
}

export function hasSeenDashboardTooltip(): boolean {
  if (typeof window === "undefined") return true
  return localStorage.getItem(DASHBOARD_TOOLTIP_KEY) === "true"
}

export function markDashboardTooltipSeen(): void {
  localStorage.setItem(DASHBOARD_TOOLTIP_KEY, "true")
}
```

## 八、动画规格

### 8.1 步骤切换动画

使用 Framer Motion `AnimatePresence`：

```typescript
<motion.div
  key={currentStep}
  initial={{ opacity: 0, x: 20 }}
  animate={{ opacity: 1, x: 0 }}
  exit={{ opacity: 0, x: -20 }}
  transition={{ duration: 0.35, ease: "easeInOut" }}
>
  {stepContent}
</motion.div>
```

### 8.2 Step 2 卡片入场

```typescript
// 每个卡片 stagger delay
variants={{
  hidden: { opacity: 0, y: 24 },
  visible: (i: number) => ({
    opacity: 1,
    y: 0,
    transition: { delay: i * 0.15, duration: 0.4 }
  })
}}
```

### 8.3 Step 4 情绪选择动画

- 选中态：`scale: 1.08` + 对应情绪色 `box-shadow`
- 按钮 hover：`scale: 1.03`
- 过渡：`spring` 弹簧动画

### 8.4 Step 5 AI 结果卡片

- 从 `y: 60, opacity: 0` → `y: 0, opacity: 1`
- type: "spring", stiffness: 200, damping: 20
- 带轻微的 overshoot 回弹

## 九、响应式规格

| 断点 | 布局 | 引导卡片尺寸 |
|------|------|-------------|
| < 768px (移动端) | 全屏单列，垂直居中 | w-full px-6 |
| 768-1024px (平板) | 居中卡片 | max-w-md mx-auto |
| ≥ 1024px (桌面) | 居中卡片 | max-w-lg mx-auto |

**移动端特殊处理**：
- 步骤圆点放大，方便手指点击
- 跳过按钮放在右上角，距边缘至少 16px safe area
- Step 4 情绪按钮 2×3 网格，每格最小 80×80px 触控区域
- 底部导航栏在 onboarding 期间隐藏

**桌面端特殊处理**：
- 卡片添加 hover 微交互
- 键盘操作支持（← → 切换步骤，Esc 跳过）

## 十、文案规范

### 品牌语调

- **不说**："点击下方按钮开始"、"请选择您的情绪"
- **要说**："来，试一次"、"选一个最贴近此刻心情的表情"
- **风格**：温暖、简洁、有呼吸感、像朋友而不是教程

### 各步骤文案

| 步骤 | 标题 | 副标题 / 提示 |
|------|------|-------------|
| Step 1 | 欢迎来到灵音 | 记录情绪的潮汐，遇见内心的风景 |
| Step 2 | 3 步，把心情变成声音 | 记录 → AI 分析 → 治愈音乐 |
| Step 3 | 你的情绪，可以听见 | 试听一下不同心情的声音 |
| Step 4 | 来，试一次 | 选一个最贴近此刻心情的表情 |

## 十二、关键边界条件

1. **网络异常**：Step 4 AI 分析如果超时/失败，显示友好提示"分析需要一点时间，你也可以先跳过，稍后在 Dashboard 再试"
2. **已有数据用户**：如果用户之前已经创建过情绪记录（user 在注册前就有数据？不会的），但仍然未完成 onboarding → 仍展示引导
3. **中途退出**：用户在 Step 2 关闭页面 → 下次登录重新从 Step 1 开始（因为未完成）
4. **多次登录**：onboarding 只展示一次，完成后永久跳过
5. **防止闪烁**：onboarding 页面使用 `"use client"` + 检查 localStorage 前先展示 loading 骨架屏
6. **PWA 环境**：确保在 PWA standalone 模式下表现正常（safe-area-inset 适配）
