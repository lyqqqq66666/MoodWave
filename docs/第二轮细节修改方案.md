## 3. 情绪录入功能增强（重点）

### 当前问题
- Step 3（记录心情）文字/图片/语音需要分别切换 tab
- 语音功能是空壳（"即将上线"）
- 图片只支持单张且不上传
- Step 4 标签不能自定义，"其他"选了没意义
- 标签必须选才能进入下一步
- Step 5 AI 分析只是固定的 insight 文本，没有真正的分析报告

### 目标效果

#### 3.1 多模态统一输入框
- **一个输入框，三种输入方式并存**：用户可以在同一个框里写文字 + 上传图片 + 录音
- 不用切换 tab，所有媒体内容集中在同一个输入区域
- 视觉设计：输入框顶部是文字区，底部是媒体附件区（图片缩略图 + 语音波形条）

#### 3.2 图片上传
- 支持多张图片（最多 3 张），显示缩略图预览
- 上传到后端 `/api/upload/image`，返回 URL 列表
- 保存到 MoodEntry 记录中

#### 3.3 语音输入
- 使用 Web Audio API 录音，或调用浏览器 MediaRecorder
- 录音后通过 AI 语音识别转文字（或用 Whisper API）
- 转写后的文字自动填入输入框（或单独展示）

#### 3.4 自定义标签
- 选择"其他"标签时，弹出输入框让用户输入自定义标签名
- 自定义标签添加到 selectedTags 数组中
- 标签可以一个都不选，直接进入下一步

#### 3.5 AI 分析报告
- Step 5 调用 DeepSeek API 生成真正的分析报告（非固定文本）
- 报告包含：情绪总结、深层洞察、调节建议、今日音乐推荐
- 可用算法（情绪分布图）：**饼图/玫瑰图** + **情绪雷达图**（6 维度：开心/平静/焦虑/愤怒/悲伤/平淡）

## 4. 情绪趋势页面优化

### 当前问题

#### 4.1 日历不可点击
- 右上角的月份日历按钮只是一个展示，不能弹出日期选择器
- 不能选择特定月份来查看数据

#### 4.2 月度情绪分布环状图
- 不触碰时不显示具体情绪类型和百分比
- 触碰到环时显示 `1:50` 之类的比例（Tooltip 默认行为）
- 没有点击交互

#### 4.3 年度热力日历令人困惑
- 当前是 10×3 的格子，只是按顺序排列，不是日历格式
- 用户看不懂是什么意思

### 目标效果

#### 4.1 日历可点击选择
- 右上角日历按钮可点击 → 弹出月份选择器（MonthsPicker）
- 选择月份后刷新整个趋势页数据（情绪日历 + 分布图 + 趋势线）
- 设计风格与主题一致（圆角、毛玻璃、柔色调）

#### 4.2 环状图优化
- **默认状态**：环外显示标签（情绪类型 + 百分比），如 "开心 35%"
- **hover 时**：高亮该环块 + 放大效果
- **点击某环块时**：主页面只显示该情绪类型对应的情绪记录列表（可滚动）
- 移除默认 Tooltip 中的 `1:50` 比例显示，自定义 Tooltip 内容

#### 4.3 年度热力日历完善
- 改为 **GitHub 贡献图风格**：7 列（周一到周日）× 若干行（周数）
- 每个格子代表一天，颜色深度代表情绪强度
- 格子上显示日期数字，hover 显示详情
- 支持左右翻月

## 6. 个人中心完善

### 当前问题

#### 6.1 头像显示问题
- Web 端头像被压扁了（宽高比不对）
- 不支持头像更换

#### 6.2 快乐能量库不完善
- 当前只是 3 个静态卡片（"高光时刻"、"连续打卡"、"治愈音乐"）
- 数据是假的，不是真实用户数据

#### 6.3 心境清单实现不明确
- 当前是静态的 checklist 示例数据
- 用户疑问：是用户自己写还是系统生成？

#### 6.4 音乐偏好区域
- 只显示标签，不显示喜爱的音乐

### 目标效果

#### 6.1 头像修复 + 更换
- 修复头像宽高比问题（使用 `aspect-square` 或固定宽高 `w-28 h-28`）
- 添加头像更换功能：点击头像 → 弹出文件选择器 → 上传到后端 → 更新显示

#### 6.2 快乐能量库完善
建议设计为：
- **高光时刻**：用户标记为"开心"且强度 ≥ 8 的情绪记录（从数据库统计）
- **连续打卡**：实际连续记录天数（从 moods 表计算）
- **音乐收藏数**：用户收藏的音乐数量
- 数据从后端 API 获取，动态展示

#### 6.3 心境清单实现方案
建议采用**混合模式**：
- **系统自动生成**（基于近期情绪模式）：
  - "本周平静天数：4天" ✓
  - "上一次焦虑在 2 天前" ✓
  - "今天适合听一首平静的音乐" ✓
- **用户自定义**：
  - 用户可以手动添加/删除清单项
  - 例如："每天冥想 5 分钟"、"本周给朋友打一个电话"
- 存储到后端 `ChecklistItem` 表

#### 6.4 音乐偏好完善
- 展示用户收藏的音乐列表（卡片：封面色调 + 曲名 + 艺术家）
- 用户可以创建自定义收藏夹名称

## 7. 登录页情绪弹幕优化

### 当前问题
- 登录页左侧原本的图形化 Mood Map 视觉模块不够自然，用户反馈"图片还是丑"
- 登录页需要更强的真实用户氛围，让新用户一进入就能感受到"这里有人记录、有人被接住"
- 当前前端已先用静态数组实现弹幕，后续需要接后端真实数据

### 目标效果

#### 7.1 登录页左侧改为舒缓弹幕
- 撤掉原来的图形/波形装饰模块
- 改为 `Mood Notes` 情绪弹幕墙
- 弹幕内容来自用户公开/匿名的情绪记录、评论、温柔回复等
- 动画要慢、轻、舒服，避免直播间式高密度刷屏
- 弹幕视觉采用半透明玻璃气泡、柔和粉/绿/蓝/奶油色，左右边缘渐隐

#### 7.2 弹幕内容规范
- 不展示用户真实昵称、头像、手机号、邮箱等个人信息
- 内容长度建议 8-40 个中文字符，过长需要截断
- 过滤敏感、攻击、隐私、联系方式、极端负面诱导等内容
- 优先展示温和、有共鸣、可被公开看到的句子

#### 7.3 数据来源
弹幕可以来自三类数据：
- 用户选择公开/匿名分享的情绪记录 `MoodEntry.note`
- 灵感广场中的公开评论/帖子 `Post.content`
- AI 生成的温柔改写句（基于真实情绪记录脱敏后生成）

## 附录：AI 模型选型建议

### 多模态输入推荐方案

| 输入类型 | 推荐模型 | 备选 | 理由 |
|----------|----------|------|------|
| **文字分析** | DeepSeek V4 | Qwen-Max / Kimi | DeepSeek 已集成，性价比最高，中文能力强 |
| **图片理解** | Qwen-VL-Max | GLM-4V (智谱) | Qwen-VL 多模态能力成熟，支持图片描述+情绪识别 |
| **语音转文字** | Whisper (OpenAI) | Qwen-Audio / 智谱语音 | Whisper 准确率最高，支持中文，成本低 |

### 模型 API 配置

```bash
# backend/.env 需要新增的配置

# ==================== 已有 ====================
DEEPSEEK_API_KEY=sk-xxx
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-pro

# ==================== 新增：阿里云百炼（Qwen）====================
DASHSCOPE_API_KEY=sk-xxx                          # 百炼 API-KEY（图片+语音共用）
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

# --- 图片理解 ---
QWEN_VL_MODEL=qwen3-vl-plus                       # Qwen3-VL 系列，视觉理解 + OCR

# --- 语音识别 ---
QWEN_ASR_MODEL=qwen3-asr-flash                    # Qwen3-ASR 系列，中文语音转文字
```

### 模型选型最终确定

| 场景 | 模型 | 平台 | 说明 |
|------|------|------|------|
| **文字分析** | DeepSeek V4 | DeepSeek API | 已有集成，中文情绪分析最佳 |
| **图片理解** | **qwen3-vl-plus** | 阿里云百炼 | Qwen3-VL 视觉语言模型，支持图片描述+情绪识别+OCR |
| **语音转文字** | **qwen3-asr-flash** | 阿里云百炼 | Qwen3-ASR 语音识别，中文准确率高、响应快 |
| **月度报告** | DeepSeek V4 | DeepSeek API | 长上下文，结构化输出 |
| **音乐推荐** | DeepSeek V4 | DeepSeek API | 基于情绪 + 用户历史 |

> 💡 **两个 Qwen 模型共用同一个百炼 API-KEY**，base_url 相同，接入成本极低。  
> 调用方式均为 OpenAI 兼容格式（`openai` Python SDK 直接调用）。

### API 调用示例

```python
# ========== 图片理解 — qwen3-vl-plus ==========
from openai import OpenAI

client = OpenAI(
    api_key="your-dashscope-key",
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
)

response = client.chat.completions.create(
    model="qwen3-vl-plus",
    messages=[{
        "role": "user",
        "content": [
            {
                "type": "image_url",
                "image_url": {"url": "https://example.com/photo.jpg"}
            },
            {
                "type": "text",
                "text": "描述图片内容、场景氛围，并分析可能反映的情绪状态。"
            }
        ]
    }]
)
# → 返回图片描述 + 情绪分析文本


# ========== 语音识别 — qwen3-asr-flash ==========
audio_file = open("recording.wav", "rb")
response = client.audio.transcriptions.create(
    model="qwen3-asr-flash",
    file=audio_file,
)
# → 返回转写后的中文文本
```
