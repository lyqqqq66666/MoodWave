## 问题 3：解忧角上下滑动左右不同步

### 影响页面

`/discovery` — 解忧角页面

### 根因诊断

**当前布局** (`discovery/page.tsx:265-266`)：
```html
<div class="grid lg:grid-cols-[0.95fr_1.45fr]">
  <!-- 左栏 -->
  <section class="lg:sticky lg:top-24 lg:self-start">
    <!-- 发布区 + 分类 + 规则 -->
  </section>
  <!-- 右栏 -->
  <section>
    <!-- 帖子瀑布流 -->
  </section>
</div>
```

**问题**：`lg:sticky lg:top-24` 在左栏内容高度 > 视口高度 - 96px 时，底部内容被裁剪无法滚动到。移动端两栏共享同一滚动容器，无法独立滚动。

### 修改方案

| # | 改动 | 文件 | 负责 |
|---|------|------|:---:|
| 3.1 | 改为真正固定左栏 + 右栏独立滚动：左栏 `lg:h-[calc(100vh-7rem)] lg:overflow-y-auto`，右栏同 | `frontend/src/app/discovery/page.tsx` | Codex |
| 3.2 | 左栏内容压缩：缩小"解忧角规则"卡片高度、减少 padding | `frontend/src/app/discovery/page.tsx` | Codex |
| 3.3 | 移动端保持现有上下堆叠布局不变 | `frontend/src/app/discovery/page.tsx` | Codex |

**具体实现参考**：
```html
<!-- 左栏：固定高度 + 内部滚动 -->
<section class="lg:sticky lg:top-24 lg:max-h-[calc(100vh-7rem)] lg:overflow-y-auto">
  ...
</section>

<!-- 右栏：独立滚动区 -->
<section class="lg:max-h-[calc(100vh-7rem)] lg:overflow-y-auto">
  ...
</section>
```

## 问题 4：头像昵称一致性与心境清单标签 bug

### 影响页面

- `/profile` — 个人主页
- 全局 — 左下角侧边栏用户信息

### 根因 A — 昵称 fallback 不一致

| 位置 | 文件 | 代码 | fallback 值 |
|------|------|------|------------|
| 左下角 Shell | `moodwave-shell.tsx:45` | `user?.username \|\| "用户"` | `"用户"` |
| 个人中心 Profile | `profile/page.tsx:128` | `user?.username \|\| "小鱼"` | `"小鱼"` |

**问题**：两个地方的 fallback 昵称不同，且登录后可能也不统一。

### 根因 B — 心境清单标签错误

`profile/page.tsx:179`：
```typescript
function addChecklistItem() {
  const text = newChecklistText.trim()  // 用户输入 "好累"
  setChecklistItems([...current, {
    text,
    mood: dominant.value as MoodType,  // ← BUG! 使用全局主导情绪
    done: false
  }])
}
```

**问题**：`dominant` 来自 `summary.dominantMood`（用户整体主导情绪），而非根据当前输入的文本内容推断。导致用户输入"好累"但标签显示"开心"。

### 修改方案

| # | 改动 | 文件 | 负责 |
|---|------|------|:---:|
| 4.1 | 统一 fallback 昵称为 `user?.username \|\| "MoodWave 用户"` | `moodwave-shell.tsx` + `profile/page.tsx` | Codex |
| 4.2 | 心境清单 `addChecklistItem()` 改为基于文本关键词推断情绪标签（复用 companion 页 `inferMood()` 逻辑） | `frontend/src/app/profile/page.tsx` | Codex |
| 4.3 | 心境清单每项增加可切换标签的下拉按钮（用户可手动修正情绪标签） | `frontend/src/app/profile/page.tsx` | Codex |

**推断逻辑参考**（复用自 `companion/page.tsx:60-67`）：
```typescript
function inferMood(text: string): MoodType {
  if (/开心|顺利|高兴|快乐|兴奋/.test(text)) return "happy"
  if (/焦虑|紧张|考试|deadline|来不及/.test(text)) return "anxious"
  if (/生气|烦|火大|愤怒/.test(text)) return "angry"
  if (/难过|失落|哭|低落|累/.test(text)) return "sad"
  if (/平静|放松|还好/.test(text)) return "calm"
  return "neutral"
}
```
