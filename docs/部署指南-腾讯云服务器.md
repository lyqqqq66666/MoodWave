## 三、服务器端部署步骤（逐条执行）

### 第 0 步：SSH 登录服务器

```bash
ssh root@你的服务器IP
# 或
ssh ubuntu@你的服务器IP
```

---

### 第 1 步：确认 Docker 环境

```bash
# 检查 Docker 是否安装
docker --version
docker compose version

# 如果没有安装，一键安装
curl -fsSL https://get.docker.com | sh

# 启动 Docker 服务
systemctl enable docker
systemctl start docker
```

---

### 第 2 步：克隆项目代码

```bash
# 进入合适的目录（建议 /opt 或 /home）
cd /opt

# clone 整个仓库
git clone https://github.com/lyqqqq66666/MoodWave.git

# 进入项目目录
cd MoodWave

# 确认文件结构
ls -la
# 应该看到: frontend/ backend/ docker-compose.yml nginx.conf AGENTS.md ...
```

---

### 第 3 步：配置生产环境变量

```bash
# 创建生产环境 .env 文件
cat > .env << 'EOF'
# ─── 数据库配置 ───
DATABASE_URL=postgresql://moodwave:你的强密码@db:5432/moodwave
DB_PASSWORD=你的强密码（不要用默认的 moodwave123）

# ─── DeepSeek API ───
DEEPSEEK_API_KEY=sk-ba819c097197479b9e4290e558b9cbfb

# ─── JWT 密钥（生产环境必须更换！）───
JWT_SECRET=生成一个强随机字符串（见下方）

# ─── 应用配置 ───
APP_ENV=production
APP_SECRET_KEY=生成另一个随机字符串
EOF

# 生成 JWT_SECRET（复制输出的随机字符串）
python3 -c "import secrets; print(secrets.token_urlsafe(32))"

# 用上面输出的字符串替换 JWT_SECRET
# vi .env  或  nano .env
```

---

### 第 4 步：确认依赖完整（重要！）

部署前必须确认 `psycopg2-binary` 已在 `requirements.txt` 中，这是 PostgreSQL 的 Python 驱动，没有它 Docker 里的 FastAPI 连不上数据库：

```bash
grep psycopg2 backend/requirements.txt
# 应该输出: psycopg2-binary==2.9.9
```

> ⚠️ 如果没有这一行，Docker 构建成功但运行时报 `ModuleNotFoundError: No module named 'psycopg2'`

### 第 5 步：确认 Docker Compose 配置

项目自带的 `docker-compose.yml` 已经配置好，关键确认：

```yaml
# 核心服务（无需修改）
services:
  db:          # PostgreSQL 16-alpine，数据卷持久化
  backend:     # FastAPI :8000，DATABASE_URL 指向 PostgreSQL
  
# 注意：docker-compose.yml 里的 DATABASE_URL 会覆盖本地开发的 SQLite，
#       部署后自动使用 PostgreSQL
```

## 四、配置 Vercel 前端连接后端

在 Vercel 控制台设置环境变量：

```
项目 Dashboard → Settings → Environment Variables

NEXT_PUBLIC_API_URL = http://你的服务器IP:8000
```

添加后点击 **Save**，然后 **Redeploy** 前端。

> ⚠️ 注意：`NEXT_PUBLIC_` 前缀的变量会被打包进前端 JS，浏览器可以直接看到。这个是给前端用的 API 地址，不是秘密。

## 五、（可选）配置 Nginx 反向代理

如果不想暴露 8000 端口，可以用 Nginx 代理到 80 端口：

```bash
apt update && apt install -y nginx

cat > /etc/nginx/sites-available/moodwave << 'EOF'
server {
    listen 80;
    server_name _;

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
EOF

ln -s /etc/nginx/sites-available/moodwave /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

> 此时 Vercel 的 `NEXT_PUBLIC_API_URL` 改为 `http://服务器IP`（不带端口号）

## 六、常用维护命令

```bash
# 查看日志
docker compose logs -f backend      # 实时日志
docker compose logs --tail=50 backend  # 最近 50 行

# 重启服务
docker compose restart backend

# 更新代码后重新部署
cd /opt/MoodWave
git pull origin main
docker compose up -d --build backend  # 只重建后端

# 进入容器调试
docker compose exec backend bash

# 数据库备份
docker compose exec db pg_dump -U moodwave moodwave > backup.sql

# 停止所有服务
docker compose down

# 彻底清理（包括数据卷，慎用！）
docker compose down -v
```

## 七、故障排查

### 问题 1：端口被占用
```bash
# 检查 8000 端口
lsof -i :8000
# 如果被占用，修改 docker-compose.yml 中 backend ports 为 "8001:8000"
```

### 问题 2：数据库连接失败
```bash
docker compose logs db
# 确认 PostgreSQL 正常启动
```

### 问题 3：DeepSeek API 调用失败
```bash
docker compose exec backend python -c "
import os
from openai import OpenAI
client = OpenAI(api_key=os.getenv('DEEPSEEK_API_KEY'), base_url='https://api.deepseek.com')
print(client.models.list())
"
```

### 问题 4：CORS 跨域
确认 `backend/src/main.py` 中 CORS 配置允许 Vercel 域名：
```python
allow_origins=["https://你的项目.vercel.app", "http://localhost:3002"],
```
